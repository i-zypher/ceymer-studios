Game case study · The funny one

A subscription you can't cancel, played for laughs.

Subscription Plus gives you a 10-minute free trial and one goal: cancel before it ends. Between you and the exit stand an avalanche of upgrades, pop-up ads you can actually buy, CAPTCHAs designed to fail you, and Brad, an AI support agent who will gladly help with anything except that.

01 / The idea

Everyone has fought a cancel button. Nobody has won.

Dark patterns are everywhere: the free trial that quietly renews, the "No thanks, I hate saving money" link, the support chat that answers every question but yours. Most people have felt it. Very few products make fun of it.

Subscription Plus turns those patterns into the game itself. Every "No thanks" asks if you're sure, then asks if you meant yes. The cookie banner has 40 partners, and some switch themselves back on. The support agent is obviously a robot who insists he isn't. And every run ends with an itemized receipt of everything you got charged for, made to be shared.

02 / Engineering decisions

The hard part was letting an AI be funny without letting it run the game.

Brad is a language model playing a character, and a character is only fun if he stays in it. The design work was deciding exactly what the model controls, and what it never does.

AI

The game owns the rules

The game, not the model, decides charges, transfers and endings. Brad only writes his lines, as strict JSON. When he pitches a made-up plan ("Pet Plus, $6.99/mo"), it comes back as a structured offer the server validates, so if the player says yes, the game can really add it to the bill.

AI

Four Brads, one escalating joke

Ask for a manager and you get the next Brad, each with his own persona, and the page itself degrades with him: a modern app, a 2014 helpdesk, a 2003 portal, then a broken 1998 page with JavaScript errors and a dead Java applet.

Cost

Guardrails that cost pennies

A small Cloud Run service with a daily dollar budget, per-run and per-IP limits, an origin allowlist and nothing the player types ever stored. If the AI is unavailable, "Brad Lite" takes over on the device, with small talk across 24 topics, so players never see an error.

Safety

An AI that reviews the AI

Every Brad reply has a Report button. Each morning, a GitHub Action reads the day's reports from Cloud Logging, has Claude judge each one (just Brad being Brad, or a real problem) and suggest prompt fixes, then files a private digest.

UX

Accessible, even when it's a joke

Light and dark themes, adjustable text size, Reduce Motion, High Contrast and captions for every sound. The audio CAPTCHA's answer is captioned too, so deaf players can pass it.

Ship

One codebase, three platforms

The same React code runs on the web and as Capacitor apps for iOS and Android, with a native share sheet, notch-safe layouts and win-back reminders that only lapsed players ever see. Every push deploys itself, with keyless sign-in to Google Cloud.

03 / What it proved

Comedy is a product discipline.

A joke only lands if everything around it works. Subscription Plus is in the portfolio because it shows an LLM character shipped with real product discipline: clear boundaries between model and game, cost limits that hold under traffic, a fallback for every failure, moderation with a human in the loop, and accessibility treated as a requirement rather than a feature.

It even has its own soundtrack. Each run plays one of six editions of the Subscription Plus jingle (polka, bluegrass, death metal and more), released as a real album, Subscription Plus! The Album.
